# Offline IP geolocation data

This app bundles the monthly IPv4 and IPv6 SBGX v1 city-coordinate bundles produced by [lollipopkit/ipgeo-shards](https://github.com/lollipopkit/ipgeo-shards). The November 2026 snapshot is included as `ip4_city_v1.bin.gz` and `ip6_city_v1.bin.gz`; `manifest.json` records the DB-IP attribution, record counts, compressed/uncompressed sizes and SHA256 checksums. On first use the app checks each compressed asset against that manifest, expands it into private application-support storage, and searches the local SBGX bucket index and records. It does not submit server IPs or hostnames to a geolocation service; hostnames are not DNS-resolved for this feature.

The SBGX files were obtained from the repository's latest GitHub release because the primary distribution manifest at `https://ipgeo.lollipopkit.com/manifest.json` was serving the older `2026-09` snapshot while the release carried `2026-11`. The repository documents `https://ipgeo.lollipopkit.com/` as its primary distribution and GitHub Releases as fallback. The bundled manifest and file hashes are checked at app startup before extraction.

Source data: [DB-IP Lite City](https://db-ip.com/db/download/ip-to-city-lite), licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). Required attribution: “IP geolocation by DB-IP (https://db-ip.com), CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).” The repository's MIT license covers its software, not DB-IP data. Test-vector coordinates are also derived from DB-IP Lite and retain this attribution.

Coordinates are city-level estimates (not an exact device location); they can indicate the network/hosting provider's registered city rather than the machine's physical location. Private/local IP addresses and hostnames are not located. An explicitly entered city remains authoritative and is not replaced by IP lookup.

To refresh the preloaded snapshot monthly, fetch the newest manifest from the primary distribution (fall back to the latest GitHub release if it is unavailable or older), download both family bundles, verify their SHA256 values and metadata against the manifest, then update the compressed assets, this manifest and `datasetVersion` in `lib/ip_geo_database.dart` together. Do not replace the checked-in parser test vectors with files generated by that parser; they are the upstream independent conformance vectors.
